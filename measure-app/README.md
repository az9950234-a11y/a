# هكتار — تطبيقات الشركة

منصة خاصة لشركة هكتار الحديثة، فيها أكثر من تطبيق من شاشة رئيسية وحدة:

- **رفع المقاسات:** مشروع، ثم تصوير كل جدار، ثم المقاسات والمواد والغرف، ثم عدد الألواح، ثم تقرير PDF.
- **عروض الأسعار:** عرض فارغ أو من مشروع مقاسات (الكميات والأسعار تنتقل تلقائياً)، مع خصم وضريبة 15%، ثم PDF احترافي.
- **حاسبة الكميات:** حساب سريع: ألواح بالعدد، دواليب بالمتر المربع (عرض × ارتفاع)، بروفايلات بالمتر الطولي، مع قائمة أسعار تتعدل، وتحويل الحساب لعرض سعر بضغطة.
- **الإحصائيات:** لوحة متابعة: المبيعات المقبولة ومقارنتها بالفترة السابقة، نسبة التعميد، العروض قيد المتابعة، العروض شهرياً، حالة العروض، أكثر البنود قيمة، الطلب على المواد، وأهم العملاء.
- **زوار الموقع:** إحصائيات hectar.sa من Google Analytics: الزوار، طلبات التواصل (واتساب، اتصال، نموذج)، الزوار يومياً، أكثر الصفحات، مصادر الزيارات، المدن والأجهزة. يحتاج المفتاح السري `APP_STATS_TOKEN` من إعدادات الموقع في Vercel.

- **سريع:** الحفظ فوري لأن البيانات تنحفظ في الجوال نفسه.
- **بدون إنترنت:** يشتغل في المواقع اللي ما فيها شبكة.
- **خاص:** المشاريع والصور على جهازك فقط. لو أحد فتح الرابط يشوف تطبيق فاضي.
- **مجاني ما يتوقف:** صفحات ثابتة على Netlify، بدون قاعدة بيانات وبدون اشتراك.

## الملفات
| الملف | الوظيفة |
|---|---|
| `index.html` | الصفحة |
| `styles.css` | التصميم (التطبيق + التقرير) |
| `app.js` | الأساس (قاعدة البيانات، الأيقونات، رسم PDF، النسخ الاحتياطي) + تطبيق رفع المقاسات |
| `quotes.js` | تطبيق عروض الأسعار + بيانات الشركة |
| `calc.js` | حاسبة الكميات + قائمة أسعارها |
| `stats.js` | لوحة الإحصائيات |
| `web.js` | زوار الموقع (يقرأ من `hectar.sa/api/app-stats`) |
| `main.js` | الشاشة الرئيسية (قائمة التطبيقات `APPS`) والتشغيل |
| `sw.js` | التشغيل بدون إنترنت |
| `manifest.json` + `assets/` | الأيقونة والشعارات |
| `../netlify.toml` | إعدادات الاستضافة |

## النشر على Netlify (مرة وحدة)
1. ادخل https://app.netlify.com وسجّل بحساب **GitHub**.
2. اختر **Add new site ← Import an existing project ← GitHub**، ووافق على وصول Netlify للمستودع.
3. اختر المستودع `az9950234-a11y/a`.
4. في **Branch to deploy** اختر `claude/exciting-tesla-eu26em`، أو `main` بعد الدمج. باقي الإعدادات تنقرأ تلقائياً من `netlify.toml`.
5. اضغط **Deploy**.
6. غيّر اسم الرابط من **Site configuration ← Change site name**، مثلاً `hectar-measure`. يصير الرابط `hectar-measure.netlify.app`.

أي تحديث ينرفع على الفرع ينشر نسخة جديدة تلقائياً.

## التركيب على الجوال (مهم)
- **آيفون:** افتح الرابط في **Safari**، ثم زر المشاركة ← **إضافة إلى الشاشة الرئيسية**. بعدها **افتح التطبيق دائماً من الأيقونة**، لأن بيانات الأيقونة منفصلة عن Safari، وiOS ما يمسح بيانات التطبيقات المضافة للشاشة الرئيسية.
- **أندرويد:** افتح الرابط في **Chrome**، ثم ⋮ ← **تثبيت التطبيق**.
- بعد التركيب افتح ⚙️ الإعدادات واضغط **تفعيل الحماية**.

## النسخ الاحتياطي
البيانات على الجوال فقط، فلو ضاع الجوال تروح المشاريع اللي ما لها نسخة.
- من ⚙️ الإعدادات اضغط **تجهيز نسخة احتياطية**، ثم **حفظ النسخة**، واحفظها في Drive أو الملفات. سوّها **أسبوعياً** أو بعد كل مشروع كبير.
- للاسترجاع على جوال جديد: ⚙️ ← **استرجاع من نسخة احتياطية** واختر الملف.
- تقارير PDF للمشاريع المقفلة ارسلها أو احفظها أول بأول من زر **مشاركة التقرير**.
