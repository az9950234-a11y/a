# موقع روبوتك CNC — Robotech CNC Website

موقع ثابت (Static) ثنائي اللغة (عربي أساسي + إنجليزي) مبني للسرعة والسيو.
لا يحتاج قاعدة بيانات ولا لوحة تحكم ولا كلمة مرور — **الكود ملكك بالكامل في هذا المستودع**.

## ما الذي بُني

| | |
|---|---|
| **38 صفحة** | 19 عربي + 19 إنجليزي، لكل صفحة نسخة مقابلة مربوطة بـ `hreflang` |
| **11 صفحة منتج** | محتوى مستقل لكل ماكينة: وصف، استخدامات، مميزات، جدول مواصفات، أسئلة شائعة، منتجات ذات صلة |
| **3 صفحات مدن** | الرياض، جدة، الدمام — صفحات سيو محلي بمحتوى مختلف لكل مدينة |
| **دليل شراء** | مقال مرجعي (فايبر أم CO2 أم راوتر، قدرة الليزر، التكلفة...) لجذب بحث "كيف أختار" |
| **صفحات أساسية** | الرئيسية، المنتجات، من نحن، تواصل معنا، 404 |

### السيو التقني المدمج
- عنوان ووصف فريد لكل صفحة ضمن الطول المثالي، وكلمات مفتاحية سعودية ("مكينة" و"ماكينة").
- `canonical` + `hreflang` (ar-SA / en-SA / x-default) على كل صفحة.
- بيانات منظمة Schema.org: `Organization`, `WebSite`, `Product`, `FAQPage`, `BreadcrumbList`, `Article`, `Service`, `ItemList`.
- `sitemap.xml` مع روابط اللغتين والصور، و `robots.txt`.
- `llms.txt` لمحركات البحث بالذكاء الاصطناعي (ChatGPT, Perplexity, Google AI).
- صور Open Graph لكل منتج (تظهر عند مشاركة الرابط في واتساب وتويتر ولينكدإن).
- خطوط مستضافة ذاتيًا + صور WebP + بدون مكتبات JavaScript → سرعة عالية.
- نتيجة Lighthouse: **SEO 100 · Accessibility 100 · Best Practices 100 · Performance 94–100**.

### التحويل (Conversion)
- زر واتساب ثابت، وشريط اتصال/واتساب سفلي في الجوال.
- نموذج طلب عرض سعر يفتح واتساب برسالة جاهزة (اسم، جوال، مدينة، ماكينة، تفاصيل) — بدون سيرفر.
- كل صفحة منتج فيها زر "اطلب عرض سعر لهذه الماكينة" برسالة باسم المنتج.
- تتبع نقرات واتساب والاتصال تلقائيًا في Google Analytics 4 (عند إضافة المعرّف).

## التعديل

كل النصوص في مجلد `content/`:

| الملف | المحتوى |
|---|---|
| `content/settings.py` | **الدومين**، الهاتف، واتساب، البريد، العنوان، روابط السوشال، الأرقام (سنوات الخبرة، الماكينات المباعة)، معرّف Google Analytics، أكواد التحقق |
| `content/ar.py` | كل النصوص العربية |
| `content/en.py` | كل النصوص الإنجليزية |

بعد أي تعديل:

```bash
python3 build.py                          # يولّد الموقع في public/
python3 -m http.server -d public 8000     # معاينة على http://localhost:8000
```

**معاينة بدون سيرفر** (تفتح بدبل كليك على `preview/index.html`):

```bash
python3 build.py && python3 preview.py
```

مجلد `preview/` للمعاينة فقط — لا تنشره (روابطه بصيغة ملفات). النشر يكون من `public/`.

يحتاج Python 3.8 أو أحدث فقط. مكتبة Pillow اختيارية (لإعادة توليد صور المشاركة): `pip install pillow`.

### إضافة منتج جديد
1. أضف المنتج في `PRODUCTS` داخل `content/settings.py` (slug، الفئة، المنتجات ذات الصلة).
2. أضف نصوصه في `PRODUCTS` داخل `ar.py` و `en.py` بنفس الـ slug.
3. ضع الصورة: `public/assets/img/products/<slug>.webp` (960×720) و `<slug>-480.webp` (480×360) بخلفية بيضاء.
4. شغّل `python3 build.py`.

### استبدال الصور
الصور الحالية مقتطعة من لقطة الشاشة للموقع القديم (دقة منخفضة). **استبدلها بالصور الأصلية عالية الدقة بنفس أسماء الملفات** في `public/assets/img/products/` ثم أعد البناء. ماكينة التنظيف بالليزر بدون صورة حاليًا وتظهر بأيقونة — أضف `laser-cleaning-machine.webp` و `-480.webp` وغيّر `"image": False` إلى `True`.

### إضافة الأسعار (اختياري)
أضف `"price_sar": 85000` لأي منتج في `settings.py` ليظهر السعر في نتائج جوجل (Product rich results).

## النشر (مجاني)

انشر مجلد **`public/`** فقط.

**Cloudflare Pages (موصى به — الأسرع في الخليج):**
1. Workers & Pages ← Create ← Pages ← Connect to Git ← اختر هذا المستودع.
2. Root directory: `robotech-website` — Build command: `python3 build.py` — Output directory: `public`.
   (بهذا أي تعديل على ملفات `content/` من GitHub مباشرة يُنشر تلقائيًا. ويمكن ترك أمر البناء فارغًا لأن `public/` محفوظ في المستودع.)
3. أضف الدومين من Custom domains.

**Netlify:** Base directory `robotech-website`، Build command `python3 build.py`، Publish directory `public`.
ملف `_headers` جاهز للكاش والأمان على المنصتين.

## قائمة الإطلاق (مهمة للسيو)

- [ ] ضع الدومين الحقيقي في `content/settings.py` ← `SITE["url"]` ثم `python3 build.py`.
- [ ] اربط الدومين بالاستضافة الجديدة (DNS).
- [ ] **تحويلات 301** من روابط الموقع القديم إلى الجديدة (ملف `public/_redirects`)، مثال:
      `/fiber-laser/  /products/fiber-laser-cutting-machine/  301` — حتى لا تضيع ترتيبات جوجل القديمة.
- [ ] Google Search Console: تحقق من الموقع، ثم أرسل `https://<domain>/sitemap.xml`.
- [ ] Bing Webmaster Tools: نفس الخطوة (يغذي أيضًا ChatGPT Search).
- [ ] Google Business Profile لكل فرع/مستودع فعلي في السعودية (أقوى عامل للسيو المحلي في الخرائط).
- [ ] أضف البريد وروابط السوشال في `settings.py` (تُضاف تلقائيًا للبيانات المنظمة).
- [ ] أضف معرّف GA4 في `settings.py` لتتبع الزيارات ونقرات واتساب.
- [ ] استبدل صور المنتجات بالأصلية عالية الدقة.
- [ ] راجع المواصفات الفنية في `ar.py`/`en.py` — هي تكوينات نموذجية للسوق ويجب مطابقتها مع موديلاتكم الفعلية.
